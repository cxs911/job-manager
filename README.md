# 求职管家 · 个人求职管理系统

一个纯前端的个人求职全流程管理工作台——可以理解为「求职场景的个人 CRM + 项目管理工具」。统一归集招聘信息、追踪投递进度、沉淀面试经验、复盘求职数据。

> 无后端、无需注册登录，打开即用；所有数据存储在浏览器本地（IndexedDB），不上传任何服务器。

## 功能特性

| 模块 | 说明 |
|------|------|
| 📊 仪表盘 | 6 项核心数据卡片、转化漏斗图、近 7 天动态时间线、近 30 天投递趋势、按赛道统计 |
| 💼 职位管理 | 全部职位 / 待投递 / 面试中 / Offer / 已结束，表格+卡片双视图，多条件组合筛选，批量操作 |
| 📇 职位详情 | 基本信息、进度事件时间线、面试笔记聚合、简历版本绑定 |
| 🎯 岗位赛道 | 固定 4 大分类（技术 / 产品 / 运营 / 售前），每个赛道可绑定专属简历，新建岗位自动匹配简历 |
| 📚 面经库 | 按公司聚合的笔试/面试题目沉淀，支持按赛道筛选 |
| 📄 简历版本管理 | 记录不同方向的简历版本与使用记录，可绑定到赛道 |
| 🏷️ 标签管理 | 自定义标签体系，用于分类筛选与统计 |
| 💾 数据导入导出 | JSON 完整备份 / CSV（Excel 可打开），兼容旧版本备份 |

## 技术栈

- **框架**：Vue 3（CDN 引入，无构建步骤）
- **路由**：Vue Router 4（Hash 模式）
- **图表**：Chart.js 4
- **图标**：Font Awesome 6
- **存储**：浏览器 IndexedDB（原生封装，无第三方库）

## 快速开始

直接用浏览器打开 `index.html` 即可。

如需以本地服务方式运行（推荐，避免个别浏览器的 file:// 限制）：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node.js
npx serve .
```

然后访问 `http://localhost:8080`。

## 数据说明

- 所有数据保存在**浏览器 IndexedDB** 中，按访问地址（域名/端口）隔离。
- 换浏览器、换访问地址或清理浏览器数据，都会导致数据"消失"。
- 建议定期在「数据导入导出」页导出 **JSON 备份**，可完整恢复数据。
- 备份文件（`求职管家_备份_日期.json` / `求职管家_数据_日期.csv`）含个人求职信息，请勿公开分享。
